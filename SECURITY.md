# Security Policy

## Supported version

Only the latest deployed commit is supported during the WebMCP Challenge judging period.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. Do not include credentials, access tokens, personal data, or an exploit against the public service in a public issue.

Reports should include the affected route or tool, impact, reproducible steps using non-sensitive test data, and a safe contact method. Receipt will be acknowledged within three business days.

## Security boundaries

External job content and model output are untrusted. WebMCP tools never replace server-side validation, authorization, idempotency, or explicit confirmation for consequential actions.
